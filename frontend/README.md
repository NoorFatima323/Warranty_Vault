# WarrantyVault™ — Frontend Web Application

This directory contains the standalone production frontend for **WarrantyVault™**.

## 📱 Micro-Screen Architecture

- **`index.html` / `01_landing_page_full.html`**: The sovereign marketing landing page with interactive simulator and ROI calculators.
- **`screens_hub.html`**: Interactive Screen Hub & catalog allowing instant navigation to all screens.
- **`login.html` / `00_auth_login_signup.html`**: Biometric auth gateway with 1-click Judge Pass.
- **`vault.html` / `02_hardware_vault.html`**: Hardware telemetry vault with live millisecond countdowns.
- **`scanner.html` / `03_optical_receipt_scanner.html`**: Optical receipt scanner with animated OCR matrix terminal.
- **`claims.html` / `04_statutory_claims_studio.html`**: Statutory RMA demand letter engine citing UCC § 2-314 & EU 2019/771.
- **`analytics.html` / `05_warranty_defense_intelligence.html`**: Defense intelligence dashboard with 96/100 defense score.
- **`demo.html`**: Full-page interactive sandbox.

## 🚀 Running Locally

```bash
# From repository root
npm run dev
# or
npx serve frontend
```
